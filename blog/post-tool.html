用 vibe coding 做我的第一个 App

2026-07-20 · #开发

vibe coding 的意思是：你负责想清楚要什么，AI 帮你把代码写出来。这个暑假，我用它做出了自己的第一个能用的 App——VIP续费提醒。

从一句话开始

我给 AI 说的第一句话是："做一个单机版、不联网、能提醒 VIP 续费日期的小工具。"它很快就给了我能跑的框架。接下来就是一遍遍告诉它"这里要改""那里加上"。

我学到的几件事

第一，描述得越清楚，结果越好。含糊的指令只会得到含糊的代码。第二，要自己看懂关键逻辑，不能完全当甩手掌柜，否则出了 bug 修不动。第三，先跑起来再追求完美。

// 一个小例子：到点提醒
if (today >= renewDate - 3) {
  showReminder("还有 3 天续费哦～");
}

现在它已经能在应用商店下载了。虽然只是个小小的工具，但它是我亲手"指挥"出来的第一个作品，意义不一样。
